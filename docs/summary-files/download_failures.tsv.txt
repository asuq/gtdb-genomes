download_failures.tsv

Output path: OUTPUT/download_failures.tsv

Fixed columns:
accession
requested_taxa
gtdb_accessions
suppressed
stage
error_type
reason
status

Notes:
One row is written for each terminal failed accession, not for every retry
attempt.
accession records the realised accession when known, otherwise the terminal
attempted or requested accession token used for that failed genome.
reason is redacted before it is written.
reason is written as a compact single-line summary with embedded line breaks
collapsed to spaces.
Suppressed stock `datasets` "no matching genome assemblies" stderr is
canonicalised to the suppression note instead of being written verbatim.
Missing primary metadata during eligibility checks is recorded with
error_type=filter_metadata_missing and status=metadata_unavailable.
Genomes excluded by NCBI criteria are recorded in the accession tables, not here.
